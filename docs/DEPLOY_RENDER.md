# Putting KidsCode online with Render

KidsCode runs on Render as **one web service**: the Node.js backend serves both the API and
the built React website. Everything is described in [`render.yaml`](../render.yaml) at the
top of the repository, so Render can set it up for you.

## What it costs

* The service uses Render's **Starter** plan with a **1 GB persistent disk**, which holds the
  SQLite database (accounts, progress, badges). Check current prices on render.com/pricing.
* The free plan is **not suitable**: its files are wiped on every restart and deploy, so all
  children's accounts and progress would be lost. If you only want a short demo, you can change
  `plan: starter` to `plan: free` and remove the `disk:` section, but treat that site as
  throw-away.

## One-time setup

1. Push the code (including `render.yaml`) to GitHub.
2. Sign in at **dashboard.render.com** (you can sign in with GitHub).
3. Click **New + → Blueprint**, connect GitHub if asked, and pick the **KidsCode-AI** repository.
4. Render reads `render.yaml` and shows a **kidscode** web service with a disk. It asks for
   the values marked `sync: false`:
   * **OPENAI_API_KEY** – your Groq key, for AI mode. Leave it empty to run the AI Coach
     offline; the site works fully either way.
5. Click **Apply**. The first build takes a few minutes (it installs everything and builds the
   website). When it finishes, open the address Render shows, e.g.
   `https://kidscode.onrender.com`.

`JWT_SECRET` and `SESSION_SECRET` are generated by Render automatically - you never type them.

## Updating the site

Every push to the `main` branch on GitHub rebuilds and redeploys automatically. The database
on the disk is kept between deploys. `backend/setup-database.js` runs on every start and only
adds what is missing (tables, the children's curriculum, the adult curriculum), so lessons are
never duplicated.

## Changing settings later

In the Render dashboard: **kidscode → Environment**. Useful ones:

| Setting | What it does |
|---|---|
| `OPENAI_API_KEY` | AI key (Groq). Empty = offline AI Coach. |
| `AI_MODEL` | AI model, e.g. `openai/gpt-oss-120b` or `openai/gpt-oss-20b`. |
| `AI_MAX_CALLS_PER_LEARNER_PER_HOUR` | Limits AI use per child (keeps free AI tiers from running out). |
| `CORS_ORIGINS` | Optional. Set to your site address (e.g. `https://kidscode.onrender.com`) to block other websites from calling your API. |

Saving changes restarts the service.

## Backups (important - this is children's data)

The database is the single file `/var/data/codequest.db` on the disk. Render keeps daily disk
snapshots on paid plans; you can also download a copy from **kidscode → Shell**:

```bash
sqlite3 /var/data/codequest.db ".backup /var/data/backup-$(date +%F).db"
```

## Your own web address

**kidscode → Settings → Custom Domains** lets you use e.g. `learn.yourschool.ac.ke`. Render
provides the HTTPS certificate automatically.

## If something goes wrong

* **Build fails with "JavaScript heap out of memory"**: add an environment variable
  `NODE_OPTIONS` = `--max-old-space-size=1536` and redeploy, or pick a larger instance.
* **Site shows "Not Found" or a blank page**: check **Logs** - the website build step must
  finish with "The build folder is ready to be deployed".
* **AI Coach says offline**: check `OPENAI_API_KEY` is set, and look for
  `AI coach provider: openai` in **Logs** after a restart.
